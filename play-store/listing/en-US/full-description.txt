LocalMD Reader is a lightweight Android app for reading Markdown stored on your device. There are no ads or login, and selected documents are rendered locally.

Open files quickly
- Open .md and .markdown files from Android's file picker or another app
- Open multiple files from Termux
- Switch between documents with tabs and restore your reading session after restart
- Return to recently opened files

Readable Markdown rendering
- View headings, lists, checklists, blockquotes, links, and tables
- Read syntax-highlighted code blocks
- Render Mermaid-compatible diagrams locally
- Search within a document and resize text with a pinch gesture
- Switch between light and dark themes and English and Japanese UI

Create Markdown from the clipboard
- Open copied text as a temporary document
- Select multiple entries from clipboard history
- Review the content, choose a file name, and save it as Markdown

Optional one-time Pro upgrade
The core reading experience is free. Pro adds convenient tools for frequently used documents.
- Markdown library with a folder tree
- Pinned files
- Additional themes
- Customizable gesture shortcuts
- Relative Markdown links and local images
- HTML export and Android's standard print flow

Privacy by design
- No ads
- No account or login
- No tracking or analytics SDK
- No app network permission
- No cloud sync

Use LocalMD Reader for local README files, AI-generated notes, technical documents, and checklists without sending their contents to an external service.
