# 公開履歴再構築後の機能監査

## 目的

公開用履歴の再構築前に存在した利用者向け機能が、現在のソースと回帰テストに残っているかを
確認する。コミットIDは履歴間で比較できないため、再構築前の最終ツリー、現在の実装、テストを
機能単位で照合した。

## 結果

| 機能 | 状態 | 根拠・対応 |
|---|---|---|
| メニュー領域の縦スクロール | 維持 | `SwipeMenuScrollView`と`MenuPanelScrollabilityTest`が存在する |
| Markdownライブラリの継続的なツリー導線 | 再実装済み | ADR-0017と現在のメニュー内ツリー実装で確認した |
| Pro機能説明の完全な日英切替 | 再実装済み | ADR-0018と`ProFeatureCatalogTest`で確認した |
| タブ長押しによるピン留め | 復元・実機確認済み | `TabPinningDecision`、操作回帰テスト、2026-08-10 Pro実機探索で確認した |
| ピン留めタブのアイコン | 復元・実機確認済み | テーマ色に追従する`ic_push_pin_18`と、ピン操作直後の表示更新を実機確認した |
| ピン留め一覧からの個別解除 | 復元・実機確認済み | 開く／個別解除を選ぶ状態とコマンド、対象だけが解除されることを実機確認した |
| ピン変更後のタブ・メニュー同期 | 復元・実機確認済み | 共通更新処理と、解除直後にタブ表示へ反映されることを実機確認した |
| ジェスチャーアクションの一意性 | 復元済み | 登録済みアクションを選ぶと新しいジェスチャーへ移動する |
| 登録済みアクションの割当先表示 | 復元済み | 日英のアクションラベルに現在の割当先を表示する |
| 一時タブを保存済みタブへ置換 | 復元済み | 型付き配置判断により元の下書きを置換し、既存の保存先タブを再利用する |
| クリップボード由来のMarkdown太字描画 | 復元済み | プレーンなMarkdownを保持し、`**`を強調表示する |
| HTML/MarkdownコードブロックのRaw/Preview切替 | 復元済み | テーマ対応切替と制限付きの安全なHTMLプレビューをテストした |
| コードフェンスメタデータ対応 | 復元済み | info stringの先頭トークンを正規化して言語として扱う |

## 復元順序

1. ピン留め操作を完了し、ローカルAPKで確認する。
2. 一時タブの保存置換を復元する。
3. Markdown太字描画を復元する。
4. ジェスチャーの一意性と割当先表示を復元する。
5. Raw/Preview切替とフェンスメタデータを一つの描画変更として復元する。

各復元は、再構築前コードの単純なコピーではなく、現在の所有モデルとADRに適合する失敗テストを
先に追加してから実装する。
