# LocalMD Reader v0.2.15

## 主な変更

- 現在のAndroid端末で、Termuxから複数のMarkdownファイルを開けない問題を修正しました。
- コマンドラインで指定した順序を保って、各ファイルをタブとして開くようにしました。
- 既存のADB・自動化向け起動契約との互換性を維持しました。

## 互換性

- Android 16（API 36）を対象とし、Android 6.0以降を引き続きサポートします。
- 広告、追跡、ログイン、アクセス解析、アプリのネットワーク権限は追加していません。

## 検証

- Android実機でTermuxから2ファイルを開けることを確認しました。
- 実機でFree版の購入キャンセルと、Pro版のピン留め、言語、ジェスチャー、Mermaid、
  コードハイライト、再起動復元の主要経路を確認しました。
- このリリース候補の準備前に、ローカルの全テストと必須CIゲートが合格しています。
