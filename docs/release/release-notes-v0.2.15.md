# LocalMD Reader v0.2.15

## Highlights

- Fixed opening multiple Markdown files from Termux on current Android devices.
- Preserved the command-line argument order when opening files as tabs.
- Kept the existing ADB and automation opening contract compatible.

## Compatibility

- Targets Android 16 (API 36) and continues to support Android 6.0 or later.
- No ads, tracking, login, analytics, or app network permission were added.

- Verified two-file Termux opening on a physical Android device.
- Verified Free purchase cancellation and Pro pinning, language, gesture,
  Mermaid, code-highlighting, and restart paths on a physical device.
- The complete local suite and required CI checks passed before this release
  candidate was prepared.
