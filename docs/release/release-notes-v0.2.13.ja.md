# LocalMD Reader v0.2.13

リリース日: 2026-07-26

## 主な変更

- Play向けFreeビルドでGoogle Playの購入導線を有効化しました。
- Google Playで買い切りのPro購入が確認されるまでは、完全なFree entitlementを維持します。
- Proの利便機能を解放しても、同じパッケージとMarkdown閲覧経路を使います。

## 互換性

- Android 16（API 36）を対象とし、Android 6.0以降の対応を維持します。
- 広告、トラッキング、ログイン、解析、アプリのネットワーク権限は追加していません。

## 検証

- Play Billingを含めつつProを初期解放しないことをビルド方針テストで検証します。
- Playへのアップロード前に全ローカルテストと必須CIチェックを成功させます。
