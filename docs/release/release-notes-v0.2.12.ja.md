# LocalMD Reader v0.2.12

リリース日: 2026-07-25

## 主な変更

- 最近開いたファイル、ピン留め、テーマ、ジェスチャーの一覧をメニュー内の折り畳み表示へ変更しました。
- 各展開内容を所有する操作行の直下へ配置し、ナビゲーションを分かりやすくしました。
- 他のジェスチャーに割り当て済みの動作を区別しつつ、再割り当てできるようにしました。
- メニューを開いたまま表示設定を変更しても、正しいアクセシビリティ操作説明を維持します。

## 互換性

- 最小対応バージョンは引き続きAndroid 6.0（API 23）です。
- 新しい権限、トラッキング、アカウント、ネットワークアクセスは追加していません。

## 検証

- 921件のユニットテストとローカルAndroidビルドが成功しました。
- メニュー、テーマ、ジェスチャー、最近開いたファイル、ピン留めの更新後の操作をAndroid実機で確認しました。
