# LocalMD Reader v1.0.0

## 最初の安定版

LocalMD Reader 1.0.0は、ローカル・オフラインで使えるAndroid向けMarkdownリーダーの
最初の製品版リリースです。

## Freeリーダー

- Androidのファイル選択、他アプリ、クリップボード、TermuxからMarkdownを開けます。
- 複数文書をタブで開き、読書セッションを復元できます。
- 文書検索とピンチによる文字サイズ変更に対応しています。
- テーブル、コードハイライト、Mermaid互換図をローカルで表示します。
- ライト・ダークテーマと英語・日本語UIを利用できます。
- 広告、追跡、ログイン、アクセス解析、ネットワーク権限はありません。

## 任意のProアップグレード

買い切りのProは、日常利用やプロジェクト文書の閲覧を快適にする機能を追加します。

- 追加テーマと高度なジェスチャーショートカット。
- 最近開いたファイルの拡張、ピン留め、Markdownライブラリ。
- 横に広いテーブルの閲覧強化と見出し移動ショートカット。
- 安全な相対Markdownリンクとローカル画像。
- HTMLエクスポートとAndroid標準の印刷フロー。

購入しなくてもFreeリーダーの全基本機能を利用できます。

## 互換性と検証

- Android 16（API 36）を対象とし、Android 6.0以降をサポートします。
- Free / Proの主要経路をJVM、プロパティベース、mutation、Gradle、エミュレータ、
  Android実機で確認しました。
- 提出前に署名済みPlay AABのバージョン、権限、Billing 9.0.0、署名の一貫性を確認しました。
