# LocalMD Reader v1.0.0

## First Stable Release

LocalMD Reader 1.0.0 is the first production-ready release of the local,
offline Android Markdown reader.

## Free Reader

- Open Markdown from Android file pickers, other apps, the clipboard, or Termux.
- Keep multiple documents in tabs and restore the reading session.
- Search documents and adjust text size with pinch gestures.
- Render tables, syntax-highlighted code, and Mermaid-compatible diagrams locally.
- Use English or Japanese UI with light and dark themes.
- Read without ads, tracking, login, analytics, or network permission.

## Optional Pro Upgrade

The one-time Pro purchase adds convenience for frequent and project-based use:

- Additional reading themes and advanced configurable gestures.
- Extended recent history, pinned documents, and Markdown library navigation.
- Enhanced wide-table navigation and heading shortcuts.
- Safe relative Markdown links and local images.
- HTML export and Android's standard print flow.

The complete Free reader remains available without purchase.

## Compatibility And Verification

- Targets Android 16 (API 36) and supports Android 6.0 or later.
- Free and Pro paths passed JVM, property-based, mutation, Gradle, emulator,
  and physical-device verification.
- The signed Play bundle was checked for version, permissions, Billing 9.0.0,
  and signing consistency before submission.
