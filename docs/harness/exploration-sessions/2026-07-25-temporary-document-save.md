# 探索セッション: 一時文書の保存と復元 (2026-07-25)

## チャーター

選択テキストを一時Markdownとして開き、名前を付けて保存し、再起動後も保存済み文書として読めるまでを一つの利用経路として確認する。

## 観測と修正

| 状態遷移 | 初回観測 | 修正後 |
|---|---|---|
| 選択テキストを開く | 一時タブと専用案内を表示 | 同左 |
| 名前を付けて保存 | 一時タブを保存済みタブへ置換 | 同左 |
| アプリを再起動 | 保存済みタブが消失 | タブと本文を復元 |

原因は、`ACTION_CREATE_DOCUMENT`の結果URIをタブとして保存する前に、文書プロバイダーのread権限を永続化していなかったことである。
`PersistableReadPermission`で結果フラグを正規化し、権限保持後に保存済みタブへ置換する順序へ修正した。

## 回帰防止

- 任意の結果フラグをread flagだけへ正規化するユニットテスト
- 権限保持が保存済みタブを開く処理より先にあることを検査する構造テスト
- 実機で保存直後、一時案内の消去、再起動後のタブと本文復元を確認
